# SmartFit Pro Landing Page

A static smartwatch storefront concept built with HTML and CSS.

## Page sections

- Product hero and navigation
- Technical specifications table
- Three product cards with local image assets
- Preorder form and newsletter layout

## Run locally

Open `index.html` in a browser, or start a local static file server from this folder.

## Project files

- `index.html` — page content and navigation
- `style.css` — page layout and styles
- `img/` — product and banner images

## Scope

This is a front-end practice project. The cart buttons, preorder form, and newsletter control are visual only; they are not connected to an order service or backend.
